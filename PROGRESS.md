# AppFleet — ход разработки

## Этап 1 — основание проекта

**Реализовано:** Git-репозиторий, Java 21/JavaFX Gradle-конфигурация, зафиксированные версии зависимостей, базовая точка входа, ротация технических логов и утверждённая структура проекта.

**Осталось:** доменная логика, GitHub REST-клиент, хранилище, безопасные операции установки, JavaFX-интерфейс, self-update, Inno Setup, CI и полный набор тестов.

**Проверки:** Java/Javac 21 x64 и Inno Setup 6 доступны локально; Gradle 8.14.3 доступен в кэше. Gradle Wrapper создан; `./gradlew.bat test` успешно завершилась (пока без тест-классов); `git diff --check` без замечаний.

## Этап 2 — домен, GitHub и сохранение состояния

**Реализовано:** строгая SemVer-логика; безопасная нормализация разрешённых ссылок GitHub; модель релизов и assets; консервативный выбор asset без выбора «первого» равнозначного файла; schema-1 валидация `appfleet-manifest.json`; официальный GitHub REST-клиент с `User-Agent`, `ETag`/`If-None-Match`, фильтрацией stable-релизов и понятными rate-limit/HTTP-ошибками; атомарные JSON-хранилища с резервной копией; модели настроек, списка репозиториев и журнала.

**Осталось:** проверка и скачивание файлов, Windows Registry/процессы, EXE/MSI/ZIP-операции, координация операций, полноценный JavaFX-интерфейс, self-update, упаковка Inno Setup, CI и документация выпуска.

**Проверки:** `./gradlew.bat test` успешно (unit-тесты плюс fixture-интеграция HTTP); `./gradlew.bat liveIntegrationTest` успешно выполнила реальную проверку GitHub API и manifest релиза `Pasha-404/sortit` `v1.5.0`; `git diff --check` без замечаний.

## Этап 3 — безопасная установка и обновление

**Реализовано:** потоковое скачивание в изолированную временную папку с отменой, прогрессом, HTTPS/host validation и проверкой свободного места; строгая проверка SHA-256; проверка Authenticode через штатный Windows API; точное read-only обнаружение standard-установки в HKCU без поиска по похожему имени; обнаружение и штатное/явно подтверждённое принудительное завершение только известных процессов; запуск Inno/EXE/MSI через массив `ProcessBuilder`-аргументов; корректная интерпретация MSI-кодов перезагрузки; ZIP-установка с защитой от Zip Slip, проверкой места, заменой через соседнюю staging-папку и откатом.

**Осталось:** оркестрация операции (подтверждения и журнал), главный JavaFX-интерфейс, скачивание манифеста/sha в сценарии, self-update, jlink/jpackage/Inno Setup, CI и итоговые инструкции выпуска.

**Проверки:** `./gradlew.bat test` успешно; добавлены проверки SHA-256, parser Registry, MSI restart code и безопасной ZIP-замены/отката; `git diff --check` без замечаний.
