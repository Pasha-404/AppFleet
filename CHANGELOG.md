# История изменений

Все существенные изменения проекта фиксируются в этом файле.

## [2.0.0] — 2026-09-08

- Проверка и установка получили явные границы доверия: SHA-256, Authenticode и результат проверки файла показываются раздельно; недействительная подпись блокирует запуск, а отсутствие подписи или недоступность средства проверки остаются предупреждением.
- Проверка локальной установки, выбор asset, кэш GitHub и ограничение запросов стали устойчивее к устаревшим данным, смене EXE, ошибкам сети и неоднозначным файлам релиза.
- Встроенные иконки EXE читаются как нативные ресурсы без запуска стороннего кода; кэш учитывает замену файла, прозрачность и исходный размер.
- Карточки приложений получили постоянное место для основного действия, предупреждения о сохранённых данных, упрощённое меню и заметную активную страницу. Настройки поясняют действие флажков и возвращают сохранённое состояние при ошибке записи.
- Окна подтверждения ограничивают длинные release notes, а ход операции отображает реальную фазу и честную границу отмены.
- BuildInfo, installer, SHA-256 и manifest проверяются как единый release-кандидат. Publisher не смешивает assets разных draft-сборок и не изменяет опубликованный Release.
- Локальный `gradlew run` берёт версию из `gradle.properties` и отключает самообновление, поэтому не предлагает обновить исходники до опубликованного релиза и не заменяет установленный AppFleet.
- Обновлены README, manifest-пример и Windows Installer Standard 2.0.0: для новых совместимых приложений обязательны точный трёхфайловый Release, `minimumAppFleetVersion: "2.0.0"`, `desktopicon`, SHA-256 и многомасштабная нативная иконка EXE.

## [1.0.11] — 2026-09-05

- Иконки карточек извлекаются напрямую из встроенных ресурсов главного EXE без запуска программы и без зависимости от Windows Shell-кэша.
- Для EXE без доступного встроенного ресурса сохранён безопасный резервный путь через Shell; маленькие значки не увеличиваются искусственно.
- Стандарт Windows-установщика дополнен обязательной многомасштабной иконкой EXE, включая слой 256×256.

## [1.0.10] — 2026-09-04

- Основной список приложений заменён на компактные карточки: действие установки или обновления видно сразу, а подробности открываются отдельно.
- Добавлена страница настроек с перезапуском приложения после обновления, очисткой установщиков и выбором ярлыка для первой установки.
- Исправлено определение системной темы Windows и синхронизация найденного EXE уже установленного приложения.
- Иконки карточек запрашиваются через Windows Shell в высоком разрешении; маленькие системные значки больше не растягиваются и не становятся размытыми.

## [1.0.9] — 2026-09-02

- Добавлена выключенная по умолчанию настройка создания ярлыка на рабочем столе при первой установке приложения.
- Ярлык создаётся только через явно объявленную безопасную задачу Inno Setup `desktopShortcutTask`; обновления не изменяют существующие ярлыки.
- Стандарт и пример manifest дополнены описанием задачи `desktopicon`.

## [1.0.8] — 2026-08-31

- Installer сохраняет совместимость с самообновлением AppFleet `1.0.0–1.0.6`, которое передавало пару `/CLOSEAPPLICATIONS` и `/RESTARTAPPLICATIONS`.

## [1.0.7] — 2026-08-31

- Исправлен перезапуск AppFleet после самообновления: тихий installer получает отдельный флаг `/APPFLEETSELFUPDATE` и запускает новую версию только в этом сценарии.
- Обычная тихая установка по-прежнему не запускает приложение без явного действия пользователя.

## [1.0.6] — 2026-08-31

- Кратковременные сетевые ошибки GitHub автоматически повторяются с ограниченной задержкой.
- При ограничении API GitHub AppFleet сохраняет последнюю проверенную строку приложения вместо «Ошибка проверки» и не отправляет повторные запросы до времени, указанного GitHub.
- Последний проверенный release и manifest сохраняются между запусками как кэш только для временной деградации GitHub.

## [1.0.5] — 2026-08-31

- AppFleet больше не считает Inno Setup успешным до появления стандартной записи реестра и главного EXE требуемой версии.
- После установки или выбора файла сбрасывается устаревший ETag, поэтому строка приложения сразу отражает новое состояние.
- Добавлен opt-in интеграционный тест реального удаления и установки SortIt через `AppFleetService`.

## [1.0.4] — 2026-08-31

- В тёмной теме исправлена читаемость пунктов контекстного меню и текста диалогов.

## [1.0.3] — 2026-08-31

- Для EXE до установки явно сообщается, что отсутствие Authenticode-подписи не блокирует установку.
- После установки неподписанного EXE AppFleet выводит предупреждение и сохраняет его в журнал.

## [1.0.2] — 2026-08-31

- Исправлено отображение текстовых полей строк в таблице приложений.
- Действие «Установить»/«Обновить» перенесено в первый столбец, чтобы оно оставалось доступным без горизонтальной прокрутки.
- Исправлена передача пути к EXE в проверку Authenticode: неподписанные установщики теперь распознаются как неподписанные и не блокируются как повреждённые.

## [1.0.1] — 2026-08-30

- Исправлена автоматическая публикация GitHub Release: повторный запуск продолжает существующий draft без создания дубликатов.

## [1.0.0] — 2026-08-30

Первый стабильный выпуск AppFleet.

- Управление установкой и обновлением Windows-приложений из GitHub Releases.
- Проверка `appfleet-manifest.json`, SHA-256, Authenticode и безопасная установка EXE, MSI и ZIP.
- Самообновление AppFleet через стандартный Inno Setup installer.
- Встроенная Java Runtime, установщик для текущего пользователя и фирменная многоразмерная иконка.
- Документация формата релизов для приложений, совместимых с AppFleet.
