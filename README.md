# AppFleet

Windows-приложение на Java 21 и JavaFX для установки и обновления приложений из публичных GitHub Releases. Проект реализует стандарт `Windows_Installer_Standard.md` и собирается Gradle Wrapper.

Полные инструкции по запуску, тестированию и выпуску будут добавлены вместе с готовым конвейером поставки. Текущая архитектура зафиксирована в [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md).
